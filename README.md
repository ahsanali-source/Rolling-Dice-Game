# GUI Dice Rolling Game

A simple and interactive desktop application built in Python that simulates rolling two dice at the same time using a Graphical User Interface (GUI).

## Features
* Displays two dice faces simultaneously.
* Generates random outcomes every time you click "Roll Dice".
* Clean and simple user interface with custom color buttons.
* Quick exit button to close the application.

## Prerequisites
Before running the project, make sure you have Python installed, along with the **Pillow** library for handling images.

You can install Pillow using this command in your terminal:
```bash
pip install Pillow
